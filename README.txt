SIMULADOR P3

INSTALAÇÃO

Na raiz do repositório corre:

npm ci

DESENVOLVIMENTO LOCAL

npm run dev

Abre no navegador o endereço indicado pelo Vite, este destina-se apenas a desenvolvimento e testes locais.

TESTES

npm test
npm run test:types

BUILD

npm run build

O resultado fica em p3-view/dist/ e deve ser publicado num
servidor de ficheiros estáticos.

APLICAÇãO MAC

Instala o ficheiro .dmg e corre a aplicação.
